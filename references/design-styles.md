# 디자인 스타일 라이브러리

이 문서는 Huashu Design의 한국어 우선 작업 흐름에서 `design-styles.md` 역할을 맡는다.

## 핵심 규칙

- 정보 건축형, 편집형, 미니멀형, 실험형, 상업형 계열을 구분한다.
- 추천 방향은 서로 다른 계열에서 골라야 비교 가치가 생긴다.
- 스타일 이름보다 구체적인 레이아웃/타입/색 전략을 제시한다.

## 보안/현지화 메모

- 사용자에게 보이는 문구는 한국어를 기본으로 작성한다.
- 외부 CDN, 원격 폰트, 무결성 없는 스크립트는 새로 추가하지 않는다.
- 동적 데이터는 `textContent` 또는 명시적 DOM 생성으로 렌더링한다.

## 완료 기준

- 결과물이 브라우저에서 열린다.
- 콘솔 오류가 없다.
- 필요한 export 또는 smoke test가 실행된다.
