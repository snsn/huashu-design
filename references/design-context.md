# 디자인 맥락 수집

이 문서는 Huashu Design의 한국어 우선 작업 흐름에서 `design-context.md` 역할을 맡는다.

## 핵심 규칙

- 대상 사용자, 사용 상황, 브랜드 자산, 경쟁 제품, 성공 기준을 먼저 묻는다.
- 모르면 placeholder를 명시하고 임의 사실처럼 쓰지 않는다.
- 맥락이 부족하면 3가지 방향 비교로 불확실성을 줄인다.

## 보안/현지화 메모

- 사용자에게 보이는 문구는 한국어를 기본으로 작성한다.
- 외부 CDN, 원격 폰트, 무결성 없는 스크립트는 새로 추가하지 않는다.
- 동적 데이터는 `textContent` 또는 명시적 DOM 생성으로 렌더링한다.

## 완료 기준

- 결과물이 브라우저에서 열린다.
- 콘솔 오류가 없다.
- 필요한 export 또는 smoke test가 실행된다.
